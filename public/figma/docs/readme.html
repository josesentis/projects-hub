AI Slides → Figma

Plugin de Figma que importa presentacions HTML fetes amb IA (Claude, ChatGPT, Gemini, reveal.js, Marp…) i les converteix en slides editables: text real, vectors, imatges i capes amb nom.

Funciona a Figma Slides (crea una slide per pàgina, escalada a 1920×1080) i a Figma Design (crea un frame per slide dins d'una secció). A Design els frames es creen a 2× la mida CSS; la versió completa també permet 3× i 4×.

Preu

La versió gratuïta importa les 3 primeres slides de cada presentació. La versió completa és un pagament únic (12 $) a Lemon Squeezy, que envia una clau de llicència per correu. Figma no accepta venedors nous, així que el cobrament no passa per Figma.

  • src/ui/license.ts: enllaç de compra i IDs de la botiga i el producte (SHOP). Amb els IDs a 0, s'accepta qualsevol clau (només per provar).
  • El panell activa la clau (una activació per ordinador) i la torna a comprovar cada vegada que s'obre. Si s'ha retornat o desactivat, el plugin torna a la versió gratuïta. Sense connexió, continua funcionant.
  • La clau es desa amb figma.clientStorage. El límit el controla src/main.ts (FREE i SCALES), no només el panell.

Provar-lo a Figma (5 minuts)

  1. npm install && npm run build
  2. Obre Figma Desktop i un fitxer de Slides (o de Design).
  3. Menú Plugins → Development → Import plugin from manifest… i tria manifest.json d'aquesta carpeta.
  4. Plugins → Development → AI Slides to Figma.
  5. Arrossega un .html o un .zip al panell, revisa la vista prèvia i prem Importa.

Fitxers per provar: test/fixtures/ (presentació amb Tailwind, una de ChatGPT, una de reveal.js, una de React, un zip amb imatges i CSS propis i un zip amb un HTML per slide).

Què fa, pas a pas

  1. Llegeix el fitxer (src/ui/ui.ts): un .html sol o un .zip. Si el zip té un index.html, fa servir aquest; si no, importa per ordre tots els HTML de la carpeta menys profunda que en tingui (cas de les eines que exporten una slide per fitxer). Els HTML de subcarpetes més endins s'ignoren: solen ser fonts o còpies de la mateixa presentació.
  2. El prepara (src/ui/prepare.ts): incrusta CSS, imatges i fonts del zip; substitueix Tailwind i Lucide pels que porta el plugin (funciona sense connexió), i afegeix una política de seguretat estricta.
  3. El pinta en un iframe aïllat amb el probe (src/probe/), que:
    • detecta les slides (reveal.js, Marp, classes .slide/.page, seccions repetides de la mateixa mida o, si és una web normal, la talla en trossos);
    • activa cada slide com ho faria el JavaScript original;
    • converteix ::before/::after en elements reals, per no perdre barres decoratives ni vinyetes;
    • llegeix posicions, colors, degradats, ombres, vores, radis, text i estils.
  4. Ho construeix a Figma (src/main.ts): frames, text amb estils per trams, SVG com a vectors, imatges, efectes i desenfocaments.

Seguretat (el tema del JavaScript)

  • El fitxer es renderitza en un iframe sandbox="allow-scripts" sense allow-same-origin: no pot llegir el panell, ni el fitxer de Figma, ni res del navegador.
  • Mode normal: els scripts del fitxer s'eliminen i una CSP amb nonce bloqueja qualsevol script que no sigui nostre.
  • Mode «Executa els scripts del fitxer»: per a fitxers que sense JavaScript surten buits (React, exportacions empaquetades com el manual de Marco Cannelloni). S'activa sol quan cal i el panell ho avisa. Els scripts continuen tancats a l'iframe aïllat i sense connect-src cap a internet.
  • El canal panell → plugin porta un token secret: res que s'executi dins el fitxer pot fer-se passar pel panell.
  • El fitxer no s'envia enlloc. L'únic accés a internet és per baixar fonts i imatges que el mateix fitxer enllaça. Es pot desactivar al panell.

Detalls que ja resol

  • Fonts: fa servir la primera font de la llista CSS que hi hagi a Figma. Si la font està incrustada amb un nom inventat ('MC Gill'), llegeix el nom real de dins del fitxer de la font (Gill Sans) i també el pes exacte. Avisa de les que falten.
  • Text: estils barrejats dins una mateixa línia (negreta, colors, subratllat, majúscules), text amb degradat (background-clip: text), ombres de text, llistes amb vinyetes o números, padding de les etiquetes de text inline.
  • Fons: colors, degradats lineals i radials, imatges (cover/contain/mosaic), degradats repetits (ratlles i quadres; es converteixen en imatge), glassmorphism (backdrop-filter).
  • Icones: SVG inline (Lucide, Heroicons…) com a vectors; fonts d'icones (Font Awesome, Material) com a imatge.
  • Animacions d'entrada: salta directament a l'estat final (incloses les que comencen amb opacity: 0).

Limitacions conegudes

  • Gràfics de Chart.js i similars: en mode normal surten com a caixa buida. Amb «Executa els scripts» s'importen com a imatge, no com a vectors.
  • transform: rotate() i clip-path no es traspassen; els elements surten rectes o sense retallar.
  • Els blend modes, mix-blend-mode i els filtres que no són desenfocament es perden.
  • Les notes del presentador de reveal.js es llegeixen, però l'API de Figma Slides encara no permet desar-les.

Què encara no s'ha pogut provar

Tot l'anterior s'ha comprovat amb el Figma simulat, no amb Figma de veritat. Els punts que cal mirar el primer dia dins Figma:

  1. Que el panell carregui l'iframe aïllat (srcdoc) dins l'iframe del plugin. Hauria de funcionar, però la CSP de Figma s'hereta.
  2. En mode «Executa els scripts»: si la CSP de Figma no permet unsafe-eval, les presentacions que fan servir Babel al navegador fallaran. React precompilat i Tailwind no en depenen.
  3. figma.createSlide() i rescale() a Figma Slides.
  4. Si algun element dona error, la importació continua i el panell mostra el primer error. Copia'l i el corregim.

Estructura

manifest.json        plugin (editorType: slides + figma)
src/main.ts          costat Figma: construeix els nodes
src/ui/              panell: lectura de fitxers, preparació, imatges, textos (ca/es/en)
src/probe/           s'executa dins l'iframe aïllat: detecció, mesura, fonts, CSS
src/shared/types.ts  format intermedi i missatges entre les tres parts
vendor/              Tailwind Play CDN 3.4.17 (Tailwind 4 i Lucide surten de node_modules)
test/                banc de proves amb Figma simulat

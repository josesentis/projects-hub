Name

AI Slides to Figma

Tagline

Turn HTML presentations made with AI into editable Figma slides.

Description

Made a deck with Claude, ChatGPT or Gemini and got an HTML file? Drop it here and get real, editable slides in Figma Slides or Figma Design: text you can edit, vectors, images and named layers. You get slides you can edit, not screenshots.

How it works

  1. Run the plugin and drop an .html file or a .zip (with its images, CSS and fonts).
  2. Check the preview: the plugin finds each slide on its own.
  3. Click Import. In Figma Slides you get one slide per page, scaled to 1920×1080. In Figma Design you get one frame per slide, inside a section.

What comes across

  • Text with mixed styles, gradients and shadows, kept as editable text layers
  • Lists, bullets and numbering
  • Backgrounds: colors, linear and radial gradients, images, glassmorphism blur
  • Icons: inline SVG (Lucide, Heroicons…) as vectors; icon fonts (Font Awesome, Material) as images
  • Web fonts, including custom @font-face fonts recognised by their real name
  • Shadows, borders, rounded corners

Works with

  • Single-file decks from Claude, ChatGPT and Gemini (Tailwind included, no internet needed)
  • reveal.js and Marp
  • React decks and bundled exports that only render with JavaScript (run in an isolated sandbox)
  • Zips with one HTML per slide

Private by design Your file is processed inside Figma, on your computer. Nothing is uploaded. The plugin only downloads fonts and images that your file itself links to, and you can turn that off.

Pricing Free: the first 3 slides of every presentation. Full version: a one-time payment for every slide, forever. Buy it from the plugin and paste your license key.

Known limits

  • Charts drawn with JavaScript import as images (turn on "Run the file’s scripts").
  • Rotations, clip-paths and blend modes are not carried over.

Data and security disclosure (answers for Figma's form)

  • Does the plugin make network requests? Yes: only to download fonts and images that the user's file references (e.g. Google Fonts, image CDNs). The user can turn this off.
  • Does it send user data or file content to any server? No.
  • Does it collect personal data? No.
  • Does it use third-party services? Only for the full version: the license key is checked with Lemon Squeezy (api.lemonsqueezy.com), our payment provider. Only the key is sent, nothing from the user's files. Tailwind, Lucide and JSZip are bundled into the plugin.
  • Does it store data? No.

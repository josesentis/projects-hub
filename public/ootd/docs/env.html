Variables d'entorn

Netlify → Site configuration → Environment variables. Es llegeixen defensivament: una variable buida, 0, negativa o no numèrica es tracta com a no posada (lib/env.ts). Una variable buida va bloquejar els desplegaments d'una altra app durant dies: tests/setup.ts buida totes les claus abans de cada test perquè mai en depenguin.

Obligatòries

Variable Per a què
DATABASE_URL Supabase (pooler :6543, ja amb prepare:false)
JWT_SECRET, APP_SESSION_ID Sessions (canviar APP_SESSION_ID tanca totes les sessions)
NEXT_PUBLIC_APP_URL Enllaços dels correus i de Stripe
SUPABASE_PROJECT_URL, SUPABASE_SERVICE_ROLE_KEY Fotos (Storage)
ANTHROPIC_API_KEY L'estilista (Claude)
GEMINI_API_KEY Les fotos dels looks (Nano Banana)
CRON_SECRET Torns de l'estilista en segon pla, push del matí, tasques diàries. Sense ella el xat no respon.

Correu i notificacions

Variable Per a què
RESEND_API_KEY, RESEND_FROM Correus (cal un domini verificat)
NEXT_PUBLIC_VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_SUBJECT Push

Models (opcionals, es canvien sense desplegar... excepte que Netlify demana tornar a publicar)

Variable Per defecte
STYLIST_MODEL claude-haiku-4-5-20251001 (dia a dia)
STYLIST_MODEL_STRONG claude-sonnet-5-5 (gust, onboarding, auditoria de l'armari)
STYLIST_TURNS_PER_HOUR 40 (topall tècnic)

Plans i pagaments (només quan es vulgui cobrar)

Variable Per a què
STRIPE_SECRET_KEY Si hi és, els pagaments s'activen (prova de 14 dies, límits per pla). Sense ella: mode beta, tot obert.
STRIPE_WEBHOOK_SECRET Signatura del webhook /api/billing/webhook
`STRIPE_PRICE__<MONTH YEAR>`
STRIPE_FOUNDER_COUPON Cupó del 30 % per als testers
COMP_MONTHLY_TOKEN_LIMIT Topall mensual de tokens per a l'accés complet (20 M per defecte)
COMP_MONTHLY_PHOTO_LIMIT Topall mensual de fotos per a l'accés complet (300)
ADS_ENABLED Anuncis al pla gratuït (apagat; cal un CMP certificat per Google abans)
LEGAL_GATE_ENABLED Demana acceptar els termes nous (apagat fins a la revisió legal)

Operació (opcionals)

Variable Per a què
CLAUDE_MONTHLY_BUDGET_USD, GEMINI_MONTHLY_BUDGET_USD Pressupost mensual: previsió i avisos
ADMIN_DB_LIMIT_GB Límit de la base de dades per a l'avís del 80 % (8)
NETLIFY_SITE_NAME Enllaç directe a Netlify als Recursos
ADMIN_LINK_BUSINESS_PLAN, ADMIN_LINK_PENDING_TESTS, ADMIN_LINK_BETA_GUIDE, ADMIN_LINK_TALLY Enllaços privats que es mostren als admins (Perfil → Recursos)
NEXT_PUBLIC_ADSENSE_CLIENT, NEXT_PUBLIC_ADSENSE_SLOT AdSense
REMOVEBG_API_KEY Treure el fons (pendent de substituir per la reconstrucció amb Gemini)
COMMIT_REF La posa Netlify sola; surt a /api/version

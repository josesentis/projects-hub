Fase 6 — Intel·ligència col·lectiva (repositori de roba comú)

Investigació i implementació. Objectiu: fer que l'app sigui més intel·ligent usant dades compartides entre usuaris (anònim/optin), sense comprometre la privacitat.

6.1 — Repositori de peces de roba "comunes"

Concepte: Una base de dades curada de peces genèriques (categories, colors, estils típics) que l'AI pot usar com a "armari universal" per completar outfits quan l'usuari no té prou peces pròpies.

  • Investigar arquitectura — taula common_wardrobe_items amb categoria, color, descripció genèrica, estil; cap imatge personal
  • Pàgina admin: gestor de peces comunes — CRUD d'items del repositori (nom genèric, categoria, tags d'estil, compatibilitats)
  • Pàgina admin: combinacions curades — admins poden afegir combinacions "provades" (p.ex. "jeans blaus + samarreta blanca + sneakers blanques = casual clàssic")
  • Pàgina admin: referències curades — bank d'imatges de referència editorial que l'AI pot usar si l'usuari no en té prou
  • Integrar common_wardrobe_items al prompt de generació d'outfits — si l'usuari no té una peça clau, l'AI suggereix la versió genèrica ("un abric beix" en lloc de nada)
  • Opt-in per a usuaris: "Contribuir el meu armari anonimitzat al repositori comú" → millora la intel·ligència col·lectiva

6.2 — Generació d'outfits amb prompt lliure

Concepte: Afegir una caixa de text a la pantalla de generació d'outfits, igual que un editor d'imatges amb IA (Adobe Firefly, Midjourney). L'usuari pot dir "genera un outfit per anar a una boda a la platja" o "vull un look més minimalista que l'últim".

  • Investigar UX — caixa de prompt col·lapsable / expandible al panell de generació
  • Passar el prompt lliure al context del missatge de Claude (com a "instruccions addicionals")
  • UI: exemples de prompts suggerits ("Per a una entrevista de feina", "Estil street casual", "Per clima fred")
  • Historial de prompts recents per reutilitzar

Phase 4 — Outfit imagery: the V1 collage system + the Premium "See it on you"

How OOTD shows an outfit. This is a product-strategy + build brief. Companion to the engine (ai/phases/phase-2-outfit-engine/), which decides what the outfit is; this phase decides how it looks.

TL;DR decision

Do NOT block V1 on generative imagery. Ship V1 with a well-designed collage / flat-lay of the user's REAL garment cut-outs (deterministic, instant, free, truthful). Reserve generative image models (e.g. Gemini "Nano Banana" / similar) for a Premium "See it on you" feature — a clearly-labelled AI visualisation, gated behind Premium, added once garment + identity fidelity is guaranteed. The earlier "ugly collages" are a design problem, not a reason to bolt on generation.

Why

  • Fidelity = the core promise. OOTD says "from what you already own." A generated image can hallucinate a jacket that isn't the user's → breaks the one thing that differentiates OOTD. Real cut-outs are the truth.
  • Cost + latency. The daily "dress me" loop must be instant & free. Generation is seconds + cents per call — wrong economics for the free, everyday output.
  • Risk surface. Generating images of people (user photos) brings likeness/rights, moderation, NSFW, and weird-artefact risks. Too much exposure for the primary output.

V1 — the collage / flat-lay system (Free, ships now)

A design task, not generation. Background removal is already in the stack (the analytics screen lists remove.bg), so clean cut-outs exist — compose them well.

Requirements

  • Editorial composition, not a dump. A layout system with hierarchy: the hero piece larger, supporting pieces and accessories smaller, arranged on a brand-consistent canvas (warm off-white or the dark editorial surface), with subtle shadows and mono item labels.
  • Templates by item count. Define clean compositions for 2, 3, 4, 5 and 6-piece outfits (most outfits are 3–5). Each template positions categories sensibly (outerwear/top/bottom/shoes/ accessory) — a deterministic placement algorithm, not random.
  • Consistency over novelty. Same grid, same treatment, same background per outfit → the feed of daily looks feels designed and premium even though nothing is generated.
  • Uses the brand system (ai/DESIGN.md / app/(dashboard)/dashboard.css): radii, hairlines, serif/mono labels, lime accent. The collage card is the same visual language as the app.
  • Instant + free + truthful. Renders from the user's real cut-outs client-side or with light server compositing; no per-render AI cost.

Output: a shareable outfit card (good for the calendar, the daily suggestion, and social sharing). Make it export/share-friendly (it doubles as organic marketing).

Premium — "See it on you" (generative, later)

This is the wow Premium hook already promised on the landing pricing ("Premium — coming soon").

  • "See it on you" — virtual try-on: the user's photo wearing the recommended pieces.
  • "Style the scene" — the look rendered in an editorial context (street, terrace, studio).
  • Engine: a generative image model (Gemini "Nano Banana" or comparable try-on/image model).
  • Guardrails (non-negotiable):
    • Garment fidelity — must clearly be the user's actual items, not look-alikes. Condition the generation on the real cut-outs; reject/flag low-fidelity results.
    • Label it AI. Always mark these as AI visualisations, distinct from the truthful collage.
    • Identity & consent — explicit opt-in for using the user's face; secure storage; deletion; rights. Treat the face photo as sensitive data (GDPR).
    • Moderation / NSFW filtering on inputs and outputs.
    • Cost control — it's a paid Premium action; meter it, cache results, set fair-use limits.
  • States: generating (with a tasteful loader), result (with regenerate / save / share), failure (graceful fallback to the collage). Latency expectation set up-front.

Roadmap fit

Free (V1) Premium (later)
Daily output Real-cut-out editorial collage optional "See it on you" upgrade
Engine remove.bg + layout/compositing generative image model + guardrails
Cost / latency ~0, instant per-generation, metered
Fidelity truthful (real items) AI visualisation (labelled)
Role the everyday product the paid "wow", drives upgrades

The generative "wow" is worth far more as a Premium feature people rave about than hidden inside the free daily output. Ship the truthful collage first; layer try-on when fidelity is provable.

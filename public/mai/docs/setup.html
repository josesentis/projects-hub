Setup Guide — App Template

Complete guide to launch a new app from this template.

Prerequisites

  • Node.js 20+ (managed via .nvmrc — run nvm use)
  • A Supabase account
  • A Netlify account
  • A Resend account (transactional email)
  • An Anthropic account (optional — only needed for AI features)

1. Clone the template

git clone <template-repo-url> my-app
cd my-app
nvm use
npm install

Replace the app name everywhere before you start:

  • package.json → "name"
  • components/Sidebar.tsx → logo text ("App Template")
  • app/layout.tsx → <title> and metadata
  • netlify.toml → site name (if specified)

2. Supabase — Database + Storage

2.1 Create a project

  1. Go to supabase.com → New project
  2. Note your Project URL, Service Role Key (Settings → API), and Database password (Settings → Database)

2.2 Run migrations

The app uses SQL migrations managed by Drizzle. Once you have your DB URL:

DATABASE_URL="postgresql://postgres.<ref>:<password>@aws-0-<region>.pooler.supabase.com:6543/postgres?sslmode=require" \
  npx drizzle-kit migrate

Or use the built-in admin endpoint after deploy: POST /api/admin/run-migrations (admin-only).

2.3 Create storage bucket

  1. In Supabase → Storage → New bucket
  2. Name: uploads
  3. Make it public (so uploaded images are served directly)
  4. Add a policy: allow authenticated users to insert/select in their own folder:
    • INSERT: bucket_id = 'uploads' for authenticated users
    • SELECT: bucket_id = 'uploads' for public

2.4 Row Level Security

The migrations enable RLS on some tables. No manual policy needed — the app uses a service role key (bypasses RLS) for all server-side DB operations.

3. Resend — Transactional email

  1. Create an account at resend.com
  2. Add and verify your domain
  3. Create an API key → copy it
  4. Set RESEND_FROM to your verified sender address (e.g. hello@yourdomain.com)

4. Google OAuth (optional)

  1. Go to Google Cloud Console → APIs & Services → Credentials
  2. Create an OAuth 2.0 Client ID (Web application)
  3. Add authorized redirect URIs:
    • https://yourdomain.com/api/auth/callback/google (production)
    • http://localhost:3000/api/auth/callback/google (local)
  4. Copy the Client ID and Client Secret

5. Apple Sign In (optional)

Apple Sign In requires an Apple Developer account ($99/year).

  1. Go to developer.apple.com → Certificates, IDs & Profiles
  2. Create a Services ID (e.g. com.yourapp.web) — this is your APPLE_CLIENT_ID
  3. Enable Sign In with Apple, add your domain and redirect URL: https://yourdomain.com/api/auth/callback/apple
  4. Create a Key with Sign In with Apple enabled → download the .p8 file
    • APPLE_KEY_ID = the key's ID (10-char string)
    • APPLE_TEAM_ID = your team ID (top-right corner of developer portal)
    • APPLE_PRIVATE_KEY = the full contents of the .p8 file (with newlines as \n)

6. Anthropic (optional — for AI analysis)

  1. Create an account at console.anthropic.com
  2. Go to API Keys → Create Key
  3. Copy the key (starts with sk-ant-…)

Without this key, the "Analyze with AI" button in References will return a 422 error. The rest of the app works fine.

7. Configure environment variables

Create .env.local in the project root. Copy this and fill in your values:

# ── App ───────────────────────────────────────────────────────────────────────
NEXT_PUBLIC_APP_URL=http://localhost:3000      # Your production URL in prod
APP_SESSION_ID=app_001                         # Change to invalidate all sessions
JWT_SECRET=change-me-to-a-random-64-char-string

# ── Database (Supabase) ───────────────────────────────────────────────────────
DATABASE_URL=postgresql://postgres.<ref>:<password>@aws-0-<region>.pooler.supabase.com:6543/postgres?sslmode=require

# ── File storage (Supabase) ───────────────────────────────────────────────────
SUPABASE_PROJECT_URL=https://<ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=eyJ...              # Settings → API → service_role key

# ── Email (Resend) ────────────────────────────────────────────────────────────
RESEND_API_KEY=re_...
RESEND_FROM=hello@yourdomain.com

# ── AI (Anthropic) ───────────────────────────────────────────────────────────
ANTHROPIC_API_KEY=sk-ant-...                  # Optional

# ── Auth: Google OAuth ────────────────────────────────────────────────────────
GOOGLE_CLIENT_ID=...apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-...

# ── Auth: Apple Sign In ───────────────────────────────────────────────────────
APPLE_CLIENT_ID=com.yourapp.web
APPLE_KEY_ID=XXXXXXXXXX
APPLE_TEAM_ID=XXXXXXXXXX
APPLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----"

# ── Cron (optional) ───────────────────────────────────────────────────────────
CRON_SECRET=change-me                         # Secret for POST /api/cron/daily

# ── Analytics (optional) ─────────────────────────────────────────────────────
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX               # Google Analytics 4 measurement ID

Minimum viable set (to run locally)

You only strictly need these to start:

DATABASE_URL=...
SUPABASE_PROJECT_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
RESEND_API_KEY=...
RESEND_FROM=...
JWT_SECRET=any-random-string

Google OAuth, Apple, and AI are all optional and fail gracefully.

8. Run locally

nvm use          # Switch to the correct Node version
npm install
npm run dev      # http://localhost:3000

Run tests:

npm test

DB migrations (if schema changed):

npm run db:generate   # Generate migration SQL from schema
npm run db:migrate    # Apply to the database
npm run db:studio     # Visual DB browser at localhost:4983

9. First admin user

After the DB is set up, register via /register. Then promote to admin directly in the DB:

UPDATE users SET role = 'admin' WHERE email = 'your@email.com';

Or use Supabase Table Editor.

10. Deploy to Netlify

  1. Push your repo to GitHub
  2. Go to app.netlify.com → Add new site → Import from Git
  3. Build settings are already in netlify.toml:
    • Build command: npm test && npm run build
    • Publish directory: .next
    • Node version: 20
  4. Go to Site settings → Environment variables → add all your production env vars (same as .env.local but with production values — especially NEXT_PUBLIC_APP_URL, DATABASE_URL, and JWT_SECRET)
  5. Deploy

Netlify-specific notes

  • The @netlify/plugin-nextjs plugin is already configured in netlify.toml
  • BCRYPT_ROUNDS=1 is set for the build step only (speeds up test hashing). Do not set this in production env vars.
  • The cron job (POST /api/cron/daily) needs to be triggered externally. Set up a Netlify scheduled function or a cron service (e.g. cron-job.org) to call it daily with Authorization: Bearer <CRON_SECRET>.

11. Post-deploy checklist

  • Register an account and verify email works (Resend)
  • Promote yourself to admin via DB
  • Upload a test image to References and verify it appears in Supabase Storage
  • Import a Pinterest board (needs a public board URL)
  • Test Google OAuth (if configured)
  • Run /api/admin/run-migrations from the admin panel to apply any pending DB migrations
  • Set up the daily cron job

Environment variables reference

Variable Required Description
DATABASE_URL ✅ Supabase PostgreSQL connection string (pooler)
SUPABASE_PROJECT_URL ✅ https://<ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY ✅ Supabase service role key (bypasses RLS)
RESEND_API_KEY ✅ Resend API key for sending emails
RESEND_FROM ✅ Sender address (must be verified in Resend)
JWT_SECRET ✅ Random secret for signing session tokens (min 32 chars)
NEXT_PUBLIC_APP_URL ✅ Full URL of the app (used in email links)
APP_SESSION_ID ✅ Change to invalidate all existing sessions (default: app_001)
ANTHROPIC_API_KEY Optional Enables AI image analysis
GOOGLE_CLIENT_ID Optional Google OAuth
GOOGLE_CLIENT_SECRET Optional Google OAuth
APPLE_CLIENT_ID Optional Apple Sign In
APPLE_KEY_ID Optional Apple Sign In
APPLE_TEAM_ID Optional Apple Sign In
APPLE_PRIVATE_KEY Optional Apple Sign In (.p8 file content)
CRON_SECRET Optional Protects POST /api/cron/daily
NEXT_PUBLIC_GA_ID Optional Google Analytics 4 measurement ID
